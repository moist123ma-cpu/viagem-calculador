Configurações

A versão V4 funciona sem chave. Para rota e pedágios automáticos, será necessária uma integração segura com API e restrições de chave.

Instalação no iPhone

Safari: abra o endereço onde o pacote estiver hospedado → toque em Compartilhar → Adicionar à Tela de Início. O pacote inclui manifest, ícones e service worker para funcionamento como PWA.

Sobre

Viagem+ V4 — otimizado para iPhone/Safari. Dados das viagens ficam armazenados localmente no dispositivo.
